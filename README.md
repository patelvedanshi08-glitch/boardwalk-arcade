# Boardwalk Arcade

Three games in one Python desktop app:
- Ludo
- Snakes and Ladders
- Treasure Race

Supports 1–4 human players, with a computer opponent in solo mode.

## Run

Install Python 3 with Tkinter, then run:

```bash
python game_arcade.py
```

No additional pip packages are required.
